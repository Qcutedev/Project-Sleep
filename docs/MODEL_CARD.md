# Model Card: โมเดลคุณภาพการนอน

ข้อมูลในหน้านี้แยกเป็นสิ่งที่ **วัดจากไฟล์โมเดลจริง** กับสิ่งที่ **ยังไม่มีข้อมูล** ตัวเลขทั้งหมดมาจาก `backend/model/sleep_quality_model.pkl` และทำซ้ำได้ด้วยคำสั่งนี้ (รันจากโฟลเดอร์ `backend`):

```bash
python scripts/inspect_model.py
```

วันที่วัด: 2 พ.ย. 2026 ด้วย scikit-learn 1.9.0

## โมเดลคืออะไร

| เรื่อง | ค่า |
|---|---|
| ชนิด | `RandomForestRegressor` 100 ต้น, `max_depth=5`, `min_samples_leaf=3`, `random_state=42` |
| ขั้นเตรียมข้อมูล | ตัวเลข: `SimpleImputer(median)` + `StandardScaler`, เพศ: `SimpleImputer(most_frequent)` + `OneHotEncoder` |
| ค่าที่รับ | `Age`, `Physical Activity Level`, `Sleep Duration`, `Stress Level`, `Gender` |
| ค่าที่ทำนาย | คะแนนคุณภาพการนอนช่วง 4–9 ซึ่ง backend แปลงเป็น 1–100 |
| ขนาดข้อมูลฝึก | 299 แถว (อ่านจากจำนวนตัวอย่างที่ root ของต้นไม้) |
| ค่าเฉลี่ยข้อมูลฝึก | อายุ 42.1 ปี, กิจกรรม 59 นาที, นอน 7.13 ชม., ความเครียด 5.39 |

ปัจจัยและคำแนะนำที่แอปแสดงเป็นกฎ if/else ใน `backend/api/main.py` และ `lib/services/sleep_advice.dart` **ไม่ได้มาจากโมเดล**

## พฤติกรรมที่วัดได้

เปลี่ยนทีละค่าจากค่าตั้งต้น นอน 7 ชม., เครียด 5, กิจกรรม 30 นาที, อายุ 25, ชาย:

| ค่าที่เปลี่ยน | คะแนนที่ได้ |
|---|---|
| ชั่วโมงนอน 0, 2, 3, 4, 5 | 51 ทุกค่า |
| ชั่วโมงนอน 6, 6.5, 7 | 59, 59, 60 |
| ชั่วโมงนอน 8, 9, 10 | 96 ทุกค่า |
| ความเครียด 1, 2, 3 | 61 ทุกค่า |
| ความเครียด 4, 5, 6 | 60, 60, 44 |
| ความเครียด 7, 8, 9, 10 | 37, 38, 38, 38 |
| กิจกรรม 0 ถึง 120 นาที | 60 ทุกค่า |
| อายุ 10, 18, 25, 30, 40, 50 | 60, 60, 60, 62, 63, 61 |
| เพศ ชาย, หญิง | 60, 60 |

จากการลองทุกชุดค่า 1,750 ชุดในช่วงที่แอปให้กรอก: คะแนนต่ำสุด 13, สูงสุด 100 และมีค่าต่างกัน 39 ค่า สัดส่วนระดับคุณภาพคือ Good 28.6%, Fair 64.6%, Poor 6.9% ชุดค่าเหล่านี้เป็นตารางที่เลือกเอง ไม่ใช่การกระจายของผู้ใช้จริง

## ข้อจำกัด

1. **นอกช่วงข้อมูลฝึก คะแนนแทบไม่เปลี่ยน** จุดแบ่งของต้นไม้อยู่ในช่วงนอน 5.95–7.95 ชม. และอายุ 28.5–51.5 ปี นอน 0 ชม. จึงได้คะแนนเท่ากับนอน 5 ชม. นี่เป็นคุณสมบัติของ random forest ที่ทำนายนอกช่วงข้อมูลไม่ได้ ไม่ใช่บั๊กของแอป ด้านนอนนานก็เช่นกัน นอน 8 ถึง 24 ชม. ได้ 96 เท่ากัน (ค่าตั้งต้นเดียวกับตารางข้างบน) การเทรนใหม่ด้วยข้อมูลชุดเดิมจึงแก้ไม่ได้ แอปจึงลดคะแนนด้วยกฎเมื่อนอนเกินเกณฑ์ตามอายุ (`lib/services/long_sleep_rule.dart`) คะแนนที่ผู้ใช้เห็นในกรณีนั้นจึงไม่ใช่ผลจากโมเดลล้วนๆ
2. **กิจกรรมทางกายแทบไม่มีผลต่อคะแนน** แม้แอปจะให้กรอกและให้คำแนะนำเรื่องนี้ คำแนะนำนั้นมาจากกฎ ไม่ได้มาจากโมเดล
3. **ผู้ใช้วัยรุ่นและผู้สูงอายุอยู่นอกช่วงข้อมูลฝึก** ฟอร์มรับอายุ 10–90 ปี แต่จุดแบ่งของโมเดลอยู่ที่ 28.5–51.5 ปี
4. **ไม่ควรตีความว่าค่าใดเป็นสาเหตุ** โมเดลเรียนความสัมพันธ์ในข้อมูลชุดเดียว
5. **ยังไม่ผ่านการตรวจสอบทางคลินิก** ใช้เพื่อการศึกษาเท่านั้น
